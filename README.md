# Réplica estrutural — página de links premium

Projeto front-end estático criado a partir da estrutura pública observável da página de referência.

## Como usar

1. Crie a pasta `assets`.
2. Adicione:
   - `hero.jpg`
   - `avatar.jpg`
   - `symbol.svg`
3. Troque os `href="#"` pelos links reais.
4. Abra `index.html` no navegador.

## Estrutura

- Hero visual com imagem de fundo
- Símbolo central sobre o hero
- Avatar sobreposto
- Nome, @ e bio
- CTA principal
- Cards de redes sociais
- 3 cards de benefícios / conteúdo
- Rodapé com aviso legal
- CTA flutuante mobile
- Layout centralizado no desktop com comportamento mobile-first

## Observação

A implementação replica a arquitetura visual e a experiência da referência, mas não inclui o código-fonte proprietário original nem copia os arquivos visuais do site.
